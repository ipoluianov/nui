# 3D

nui draws 3D scenes in software, with no GPU and no C libraries: models of
OBJ and STL files, generated shapes, surfaces of functions, point clouds,
lines and labels, lit and shaded, with smooth edges. `View3D` is a widget
that shows a scene and lets the user turn, move and zoom it with the mouse
and the keyboard, and pick its objects.

Run `go run . viewer3d` for a viewer of models and surfaces.

```go
scene := ui.NewScene3D()
torus := scene.Add(ui.NewTorusMesh(1, 0.35, 64, 32), ui.Material{
	Color:    color.RGBA{230, 120, 40, 255},
	Specular: 0.5,
})
torus.Name = "torus"
scene.AddGrid(6, 0.5, color.RGBA{128, 128, 128, 255})
scene.AddAxes(2)

view := ui.NewView3D(scene)
view.OnPick.Connect(func(h ui.Hit3D) {
	fmt.Println("clicked", h.Object.Name, "at", h.Point)
})
form.Panel().AddWidget(0, 0, view)
```

## Coordinates

The space is right-handed, as in OpenGL and most model files: x to the
right, y up, z towards the viewer. Angles are in radians.

## The scene

`Scene3D` holds:

| Field | |
|---|---|
| `Objects` | meshes with their materials and transforms (`Add(mesh, material)` returns the `*Object3D`) |
| `Lines` | lines of a width in pixels: `AddLine`, `AddPolyline`, `AddGrid(size, step, color)`, `AddAxes(length)` |
| `Points` | dots of a size in pixels: `AddPoint` — clouds of points, markers |
| `Labels` | texts at points: `AddLabel(p, text, color)`, drawn over the scene with the canvas' font |
| `Lights` | `ui.Light`; without lights the scene is lit from the viewer's upper right with a soft light around |
| `Ambient` | the light from all around, 0..1 |
| `Background` | the color behind; transparent shows what is under |
| `ClipPlanes` | cutting planes, a section view: see below |
| `SectionColor` | the color of the inside seen through a cut (zero: each object's color, darker) |

An `Object3D` has a `Name`, a `Mesh`, a `Material`, a `Transform` (a
`ui.Mat4`; the zero value is the identity), `Hidden`, and `Data` for the
application.

```go
o := scene.Add(mesh, mat)
o.Transform = ui.Translate4(ui.V3(0, 1, 0)).Mul(ui.RotateY4(angle)).Mul(ui.Scale4(ui.V3(2, 2, 2)))
```

`Mat4.Mul` applies the right matrix first: the example scales, then turns,
then moves.

## Meshes

A `Mesh` is triangles: `Positions`, and `Indices` three per triangle,
counterclockwise when seen from the outside. `Normals`, `UVs` (texture
points, V up) and `Colors` (of the corners, mixed across the triangles) are
optional; the normals are computed when missing.

Shapes, all centered at 0, 0, 0:

| Function | |
|---|---|
| `NewBoxMesh(sx, sy, sz)` | a box with sharp edges |
| `NewSphereMesh(r, segments, rings)` | a sphere |
| `NewCylinderMesh(rBottom, rTop, height, segments, caps)` | a cylinder or a truncated cone |
| `NewConeMesh(r, height, segments)` | a cone |
| `NewTorusMesh(r, tube, segments, sides)` | a ring |
| `NewPlaneMesh(sx, sz, nx, nz)` | a floor |
| `NewSurfaceMesh(x0, x1, z0, z1, nx, nz, f)` | the graph of `y = f(x, z)`; NaN leaves holes |
| `NewShapeMesh(name)` | one of the above by its name |

Solids of 2D profiles, as CAD programs make parts of sketches:

| Function | |
|---|---|
| `NewExtrudeMesh(outline, holes, height)` | the polygon with the holes in the plane z = 0 pushed up to z = height: a plate, a profile |
| `NewLatheMesh(profile, segments)` | the profile `(radius, height)` turned around y: a shaft, a bushing, a vase; draw the half section counterclockwise |
| `TriangulatePolygon(outline, holes)` | the triangles of a polygon with holes (ear clipping): for meshes of your own |

The sides of a profile turning by less than 30 degrees are shaded smooth
(the arcs of an outline, sampled), the others meet at sharp edges.

```go
// A plate with a bore, lying on the floor
plate := ui.NewExtrudeMesh(outline, [][]ui.PointF{bore}, 12)
plate.Transform(ui.RotateX4(-math.Pi / 2))
```

Files:

| Function | |
|---|---|
| `LoadOBJ(r)` | Wavefront OBJ: `v` (with vertex colors), `vt`, `vn`, `f` of any count of corners |
| `LoadSTL(r)` | STL, binary or text |
| `LoadMeshFile(path)` | either, by the extension |
| `mesh.WriteOBJ(w)` | writes OBJ |

And: `ComputeNormals()`, `Bounds()`, `Transform(m)`, `Center(size)` (fit
any model into a box of the size around 0, 0, 0), `Append(other)`,
`ColorByHeight(stops)` (color a terrain or a surface by its height),
`TriangleCount()`.

If the slices of a mesh are changed in place, call `mesh.Changed()`: the
view then draws it again (it keeps the picture of the last frame while
nothing changes).

```go
// The surface of a function, colored by its height
m := ui.NewSurfaceMesh(-3, 3, -3, 3, 80, 80, func(x, z float64) float64 {
	return math.Sin(x) * math.Cos(z)
})
m.ColorByHeight([]ui.GradientStop{{0, blue}, {1, yellow}})
scene.Add(m, ui.Material{DoubleSided: true, Color: white})
```

## Materials

| Field | |
|---|---|
| `Color` | the color of the surface (zero: light gray); an alpha below 255 makes it translucent |
| `Texture` | an `image.Image` placed by the mesh's `UVs`, repeated past 0..1 |
| `Specular`, `Shininess` | the strength (0..1) and the size of the highlights |
| `Unlit` | the colors as they are, without light and shade |
| `Flat` | one tone per triangle: a faceted look |
| `DoubleSided` | draw the back sides too: open surfaces, sheets |
| `Wireframe` | only the edges of the triangles, in `Color` |
| `EdgeColor`, `EdgeWidth` | the edges drawn over the surface: the borders, the creases (turns of more than 30°) and the outline of the curved sides seen from the camera, not the diagonals of flat sides — the look of CAD |

The colors of the material, the corners and the texture multiply.

## Lights

```go
scene.Lights = []ui.Light{
	{Kind: ui.LightDirectional, Direction: ui.V3(-1, -2, -1)},            // the sun
	{Kind: ui.LightPoint, Position: ui.V3(0, 3, 0), Color: warm, Intensity: 0.6},
	{Direction: ui.V3(0, 0, -1), FromCamera: true, Intensity: 0.3},       // from the viewer
}
scene.Ambient = 0.2
```

The lighting is computed for every pixel (Blinn-Phong).

## Sections

```go
scene.ClipPlanes = []ui.Plane3D{{Point: ui.V3(0, 0, 0), Normal: ui.V3(-1, 0, 0)}}
scene.SectionColor = color.RGBA{220, 70, 60, 255}
```

Of each object only what is on the side the normal of every plane points to
is drawn and picked (up to six planes). The inside of a closed object seen
through the cut is drawn in `SectionColor`, so the cut looks filled, as in
the section views of CAD programs. The lines, the points and the labels of
the scene are not cut.

## The camera

`ui.Camera` has `Position`, `Target`, `Up`, `FOV` (vertical, radians),
`Orthographic` with `OrthoHeight`, and `Near`, `Far` (zero: taken from the
scene). `NewCamera(position, target)` makes a perspective one.

- `cam.Project(p, w, h)` — where a point of the scene is in a picture of
  the size: to put 2D things next to 3D ones;
- `cam.Ray(x, y, w, h)` — the ray through a point of the picture;
  `scene.Pick(ray)` returns the nearest triangle it hits (`Hit3D`: the
  object, the triangle, the point, the normal, the distance).

## View3D

| Mouse and keys | |
|---|---|
| left button drag | turn around the target |
| right or middle drag, Shift + left drag | move |
| wheel | zoom towards the pointer |
| click | pick: `OnPick` |
| double click | center on the point under the pointer; on nothing, show the whole scene |
| arrows, Shift + arrows | turn, move |
| `+`, `-`, Page Up, Page Down | zoom |
| `1`, `3`, `7` | look from the front, the right, the top |
| `5`, `O` | perspective / orthographic |
| Home, `R` | back to the first view |

| Method | |
|---|---|
| `SetScene`, `Scene` | the scene shown |
| `FitToScene`, `ResetView` | see all of the scene; go back to the first view |
| `SetView(target, distance, yaw, pitch)`, `View()`, `Camera()` | the camera of the orbit |
| `SetOrthographic`, `SetFieldOfView` | the projection |
| `SetAntialias(n)` | the samples per pixel side of the still view (default 2) |
| `SetAutoRotate(speed)` | turn by itself, radians a second |
| `SetAxesGizmo(true)` | the axes in the lower left corner, turned with the view; a click on an axis looks along it, a second click from the other side |
| `SetHoverPicking(true)`, `OnHover`, `Hovered()` | the object under the pointer as it moves |
| `SetOverlay(f)` | draw 2D things over the scene: a legend, a scale |
| `SetControlsEnabled(false)` | a view the user cannot move |
| `PickAt(x, y)`, `Project(p)` | picking and projecting in the widget's coordinates |
| `RenderImage(w, h)` | a picture of the view, to save or copy |
| `Invalidate()` | draw again after a change the view cannot see |
| `OnPick`, `OnHover`, `OnViewChanged` | signals |

While the view moves, it is drawn without smoothing to keep up with the
mouse, and smoothed when it stops. While nothing changes it keeps its last
picture: other widgets of the window repaint without drawing the scene
again.

In XML: `<view3d model="part.stl" color="#4080e0" axes="true" grid="true"/>`
or `<view3d shape="torus" autorotate="0.5"/>` ([xml_layout.md](xml_layout.md)).

## Drawing 3D on any canvas

`cnv.Draw3D(x, y, w, h, scene, camera)` draws a scene in a rectangle of any
canvas: in a custom widget, next to a chart, into an image. A
`Renderer3D` does the same with buffers of its own, kept between frames
(use one per place drawn often), and tells what it drew:

```go
r := ui.NewRenderer3D()
r.Antialias = 3 // 9 samples a pixel
img := r.RenderImage(1920, 1080, scene, cam)
fmt.Println(r.Stats()) // triangles, lines, points, time
```

## How it works, and what it costs

The renderer transforms the corners on all the processors, cuts the
triangles at the near plane, leaves out the back sides and what is out of
view, and rasterizes the rows in bands on all the processors with a depth
buffer. The depth of every sample is found first, so a pixel is lit once,
by the surface seen there. Colors, normals and texture points are
interpolated with the perspective; translucent triangles are sorted from
far to near and blended. The edges are smoothed by supersampling.

On a 4-core desktop CPU of 2014 (Core i5-4460), 800 × 600:

| Scene | Time |
|---|---|
| a sphere of 16 000 triangles, no smoothing | 8.5 ms |
| a shiny torus filling the view, 800 × 700, smoothed (4 samples a pixel) | 50 ms |
| the same, while it moves (1 sample) | 14 ms |

The cost grows with the pixels and the samples more than with the
triangles: hundreds of thousands of triangles are fine. Big translucent
objects, many lights with highlights, and `Antialias` 3 cost the most.

Not done: shadows of objects on each other, reflections, mipmaps of
textures, the materials of OBJ files (`.mtl`), caps of the sections of open
surfaces, boolean operations on solids.
