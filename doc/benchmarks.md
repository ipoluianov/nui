# Бенчмарки nui

Измеряется то, от чего зависит, отзывчив ли интерфейс. Формы показываются в headless-режиме (`ui/uitest`), поэтому цифры отражают работу самой библиотеки, без отрисовки системой.

```
go test ./ui/benchmarks -run xxx -bench . -benchmem          # всё, около 1,5 минуты
go test ./ui/benchmarks -run xxx -bench . -benchmem -short   # без 20 000 строк, около 15 секунд
```

После изменений, которые касаются раскладки, отрисовки или текста, бенчмарки запускаются заново, и строка с новыми цифрами добавляется в таблицу ниже. Так видно, что изменение дало и не откатилось ли что-то.

## Что измеряется

| Бенчмарк | Сценарий |
|---|---|
| `TextBoxSetText/N` | загрузка текста из N строк в многострочный TextBox |
| `TextBoxKey/N` | ввод одного символа в TextBox с N строками (нажатие, символ, отпускание), без перерисовки |
| `TextBoxPaint/N` | один кадр формы с таким TextBox, например мигание курсора |
| `AddWidgets` | 1000 меток, добавленных по одной в уже показанную форму |
| `LabelSetText` | смена текста одной метки на форме с 300 метками |
| `TableFill` | заполнение таблицы 100 000 × 5 через `SetCellText2` |
| `TablePaint` | один кадр формы с такой таблицей |
| `EmptyFormPaint` | кадр пустой формы 2560×1440 — нижняя граница любой перерисовки. В цифру входит выделение буфера кадра (14,7 МБ) |

## Результаты

Время на одну операцию; в скобках — память, выделенная за операцию.

### 2026-10-25, исходное состояние (до фазы 1)

Intel Core i5-4460 3,2 ГГц, Linux, Go 1.27.1.

| Бенчмарк | 500 строк | 2 000 строк | 20 000 строк |
|---|---|---|---|
| `TextBoxSetText` | 112 мс (27 МБ) | 477 мс (429 МБ) | 15,7 с (40 ГБ) |
| `TextBoxKey` | 41 мс (13 МБ) | 182 мс (214 МБ) | 7,4 с (20 ГБ) |
| `TextBoxPaint` | 29 мс (3,4 МБ) | 147 мс (10 МБ) | 5,5 с (531 МБ) |

| Бенчмарк | Время | Память |
|---|---|---|
| `AddWidgets` (1000 меток) | 3,26 с | 1,1 ГБ, 14,7 млн выделений |
| `LabelSetText` | 0,81 мс | 253 КБ |
| `TableFill` (100 000 × 5) | 185 мс | 105 МБ, 1,8 млн выделений |
| `TablePaint` | 3,3 мс | 3 МБ |
| `EmptyFormPaint` (2560×1440) | 4,6 мс | 14,7 МБ (буфер кадра) |

Ориентир: кадр при 60 Гц длится 16 мс. Всё, что дольше на один ввод или кадр, пользователь замечает. Цели фаз 1 и 3 плана:
- `AddWidgets` — до 50 мс;
- `TextBoxKey` и `TextBoxPaint` на 20 000 строк — до 16 мс.
